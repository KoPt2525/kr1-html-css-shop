# Учебный интернет-магазин ShopProject

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина: главная страница, каталог с фильтрами, подробная карточка товара, страница оформления заявки и контакты. Проект выполнен без CSS-фреймворков; JavaScript используется минимально — только для модального окна и базовой проверки формы.

## Страницы

| Страница | Содержимое |
|---|---|
| `index.html` | hero-блок, преимущества, популярные товары с бейджами, модальное окно заявки |
| `catalog.html` | статический блок фильтров (категории, цена) и 12 фото, сгруппированных по категориям: котята и щенки, еда, машинки, достопримечательности |
| `product.html` | изображение, описание, цена, наличие, таблица характеристик, блок «Как получить фото» |
| `order.html` | форма заявки: имя, e-mail, телефон, товар, количество, дата, комментарий, согласие |
| `contacts.html` | контакты, ссылка на форму заявки |

На всех страницах: уникальные `title` и `meta description`, общее меню с выделением текущей страницы, хлебные крошки на внутренних страницах, подключение `css/style.css`, один `main`.

## Выполнение требований КР №1

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- **Навигация:** единое меню на всех страницах, якорные ссылки `index.html#advantages` и `index.html#popular`, хлебные крошки.
- **Карточки:** блок `product-card` в сетке `products-grid`.
- **Таблица:** характеристики товара на `product.html` (`caption`, `thead`, `tbody`, `th`, `td`).
- **Форма:** в модальном окне на главной и в каталоге и отдельной страницей `order.html`; `label` связаны с полями через `for`/`id`, есть `required`, `type="email"`, `pattern` для телефона.
- **Модальное окно:** элемент `dialog` на главной странице и в каталоге.
- **CSS:** переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`, подсветка ошибок через `aria-invalid`.
- **Flex/Grid:** Flexbox — меню, карточки, кнопки; Grid — сетка товаров, каталог «фильтры + товары», страница товара, блок преимуществ.
- **БЭМ:** все компоненты названы по схеме `block__element--modifier`, стилизация через `id` и inline-стили не используется.
- **Позиционирование:**
  - `position: relative` — карточка товара и блок изображения на странице товара;
  - `position: absolute` — бейджи «Хит», «Новинка», «−10%»;
  - `position: sticky` — панель фильтров в каталоге остаётся на экране при прокрутке;
  - `position: fixed` + `z-index` — кнопка «Наверх».

## Самостоятельные доработки

Сверх пошаговых методических указаний:

- **Собственный контент:** вместо шаблонных «Товар 1…3» — 12 собственных фотографий из поездки, оформленных как товары.
- **Каталог по категориям:** фото разбиты на 4 группы (`catalog-group`) с якорями `#pets`, `#food`, `#cars`, `#places`; фильтры переделаны под эти категории. Карточки с главной ведут на нужную группу каталога.
- **Фон всех страниц** — фото Фудзиямы с полупрозрачной белой подложкой (`linear-gradient` поверх `url()` в одном `background-image`) и `background-attachment: fixed`.
- **Фото в карточках одинакового размера:** вертикальные снимки вписаны в рамку 4:3 через `aspect-ratio` и `object-fit: cover`; картинки ниже первого экрана грузятся лениво (`loading="lazy"`).
- **Варианты карточек через БЭМ-модификаторы:** `--featured` (рекомендуемый товар), `--discount` (скидка, красная цена), `--unavailable` (нет в наличии, кнопка отключена через `disabled`).
- **Отдельный блок `badge`** с модификаторами `--hit`, `--new`, `--sale`; используется и в карточках, и на странице товара (БЭМ-микс `badge product-card__badge`).
- **Страница товара:** раскладка «изображение + информация» на Grid, блок наличия, расширенная таблица с подсветкой строки при наведении.
- **Страница заявки:** выбор товара и количества, отметка обязательных полей звёздочкой, кнопка «Очистить», которая сбрасывает и подсветку ошибок.
- **Кнопки двух видов:** `button--primary` и `button--secondary` (контурная).
- **Доступность:** `aria-current="page"` у текущего пункта меню и в хлебных крошках, `aria-describedby` связывает поле телефона с подсказкой формата, `role="status"` у сообщения об успешной отправке, видимый фокус у всех интерактивных элементов, `scope` у ячеек-заголовков таблицы, `alt` у изображений.
- **Заказ прямо из каталога:** кнопка «Заказать» в любой карточке открывает окно заявки, а в окне видно, какой товар выбран («Вы заказываете: …»). После отправки страница прокручивается к сообщению об успехе.
- **JavaScript работает на трёх страницах:** скрипт проверяет, есть ли на странице модальное окно, и не падает на `order.html`, где форма размещена без него.
- **Ссылки в контактах:** телефон и e-mail кликабельны (`tel:`, `mailto:`).

## CSS-архитектура

Файл `css/style.css` разделён на 5 блоков:

1. Переменные проекта (`:root`) — цвета, отступы, скругления, ширина контейнера.
2. Базовые стили — `html`, `*`, `body`.
3. Общие элементы — ссылки, `:target`, `button`, `badge`, `to-top`.
4. Компоненты страниц — шапка, меню, хлебные крошки, hero, карточки, каталог, страница товара, таблица, подвал.
5. Форма и модальное окно.

## БЭМ-блоки

`site-header`, `site-nav`, `site-main`, `site-footer`, `breadcrumbs`, `hero`, `section`, `advantages-list`, `products-grid`, `product-card`, `badge`, `catalog-layout`, `catalog-filters`, `catalog-products`, `filters-form`, `product`, `product-table`, `contacts-list`, `aside-info`, `order-dialog`, `order-form`, `success-message`, `button`, `to-top`.

Примеры модификаторов: `site-nav__link--active`, `product-card--featured`, `product-card--discount`, `product-card--unavailable`, `badge--sale`, `button--primary`, `button--secondary`, `order-form--page`, `product-table__cell--name`.
